How the figure is made — and what it is not

Every row shows the same decomposition: TVL → size curve → value if it launches → token odds → implied value. The size curve is fitted on the traded tokens in this snapshot, and only on them; the odds are fitted on the eligible peers, and only on them. No protocol's name is hardcoded anywhere in the program — the ranking, the odds and the verdicts all come from the snapshot's figures, and running the program on a later snapshot would rank that snapshot's protocols the same way. A protocol whose name matches a traded token's stem or symbol is flagged Kin: it may be a sibling product of a token that already trades, and its odds are read with that in mind.

Seven-day growth is clamped to −60% / +120% so one wild week cannot price a protocol, and a missing growth figure is read as flat. A missing listed date is read as the peer median age. TVL is read as printed; a protocol's market cap, when DefiLlama records one, is never used to rank it — traded tokens are comps, never candidates. The board is deterministic: the same snapshot always writes the same board, and the bootstrap rank ranges come from 200 refits on a fixed seed.

What this is not: a prediction that a token will be issued, a promise of an airdrop, or financial advice. Farming costs real gas and real hours, and the drop a protocol pays, if it pays one, is its own decision. The verdicts compare farming with a T-bill and with $25 an hour of your time because those are the alternatives a reader actually has.
